# Digital Marketing & WordPress Interview Bootcamp — Arabic Guide | معسكر مقابلات التسويق الرقمي وووردبريس

دليل عربي تفاعلي للتحضير لمقابلات العمل في **التسويق الرقمي (Digital Marketing)** و**تطوير وتصميم WordPress**، مصمم كصفحة ويب عربية RTL تساعد على مراجعة الأسئلة والمفاهيم المهمة بطريقة منظمة وسريعة.

An Arabic interactive **Digital Marketing and WordPress interview preparation guide** for marketers, media buyers, SEO specialists, and WordPress professionals preparing for job interviews.

## 🎯 What This Project Covers

- Digital Marketing interview preparation
- WordPress interview preparation
- SEO concepts and interview topics
- Paid advertising / media buying concepts
- Website and CMS-related knowledge
- Search and category filtering
- Interactive learning and progress-oriented UI
- Arabic RTL user experience

## ✨ Features

- Arabic RTL layout
- Searchable interview content
- Category filters
- Responsive modern interface
- Interactive learning components
- Single-file web app that runs directly in the browser
- No framework or build process required

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- RTL Arabic UI
- Google Fonts

## 🚀 Run Locally

```bash
git clone https://github.com/reyad-dev/digital-marketing-wordpress-interview-arabic.git
cd digital-marketing-wordpress-interview-arabic
```

Then open `index.html` in your browser.
